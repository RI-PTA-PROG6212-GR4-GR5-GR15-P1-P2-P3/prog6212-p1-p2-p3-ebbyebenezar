# RaceDay 🇿🇦

## Road Running, Walking and Cycling Event Management System

RaceDay is a full-stack web-based event management system designed for the South African road running, walking, and cycling community.
The system aims to replace paper-based registration, spreadsheets, and disconnected communication with one central platform where Event Organisers can manage events and Participants can enter events, view information, and track their performance.

## 📌 Project Overview

South Africa hosts many road running, walking, and cycling events, including major events such as the Comrades Marathon, Cape Town Cycle Tour, Soweto Marathon, and Two Oceans Marathon.
Many smaller events still rely on manual processes, which can make it difficult to manage organisers, participants, registrations, rresults, and event .
RaceDay provides a digital solution that allows event information and participant data to be managed in one system.
